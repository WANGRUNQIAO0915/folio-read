# Windows 机构访问与 PDF 导入

此功能只提供 Windows 独立窗口的手动访问流程，不代表已验证学校订阅、CARSI 或所有出版社兼容性。网页版和 Android 不提供这个内置窗口。

1. 在顶部菜单选择 **文件 → 机构访问并导入 PDF（临时会话）**。
2. 点击“西南交大官方 VPN 指南”，按照学校官方说明自行认证。若学校要求单独 VPN 客户端，需要自行按学校要求配置；此窗口不会代替系统 VPN。
3. 选择保存到的软件文件夹。通过学校入口访问论文，也可点击 ScienceDirect。单独打开 ScienceDirect 不保证会继承学校代理的访问路径；请以学校门户内提供的资源链接为准。
4. 找到有权访问的论文后，点击 **允许下一次 PDF 下载（2 分钟）**，再点击网页的 PDF 下载按钮。若页面只是内嵌显示 PDF，可使用 PDF 查看器的下载按钮。每次只允许一个下载；没有批量抓取。
5. 下载完成后自动检查 PDF 并导入。新论文在所选文件夹中准备阅读，不会自动开始付费 AI 翻译。相同 PDF 使用内容指纹去重，原分类和笔记保持不变。回到文献库刷新可看到结果。
6. 下载过程中可取消。点击 **关闭并清除会话** 结束访问。再次打开是新的临时会话；已经完成的导入不会撤销。

## 访问边界

- 学校与 ScienceDirect 的 HTTPS 主站/子域可直接导航；跳到其他 HTTPS 域名时显示原始域名，请确认它是可信的学校认证或出版社站点后再继续。
- 不支持 HTTP、文件地址、本机地址、不安全证书绕过或自动弹窗。部分特殊 SSO 流程可能不兼容，可改用普通浏览器下载后手动导入。
- 页面没有 Folio Read 的 JavaScript/主机对象接口，不使用主应用的浏览器缓存。相机、麦克风、位置等网页权限默认拒绝。
- 账号认证完全由你在浏览器内操作。程序不读取或导出 Cookie、密码、localStorage、令牌，不记录含认证参数的访问 URL，不重放出版社请求。

## 临时数据与文件检查

使用独立的 WebView2 InPrivate 临时目录，禁用浏览器密码保存和表单自动填充，不提供“记住登录”选项。关闭时释放浏览器并尝试删除整个临时目录。系统崩溃、强制结束进程或文件仍被系统占用时，可能残留临时缓存；InPrivate 不是操作系统磁盘加密。请在可信的个人电脑上使用。

下载只写入随机命名的临时文件，不采用网站提供的路径。最多 100 MiB，检查有效 PDF、加密状态、页数及嵌入附件/主动内容等结构；不是杀毒软件，也不保证任何 PDF 都安全。HTML 登录页、损坏或加密 PDF、不允许的主动内容不会导入。

## 开发验证

- `python -m unittest discover tests` 覆盖校验、去重与文件夹行为。
- `python scripts/test_institutional_windows.py` 使用 Windows 的真实 WebView2 和本机合成 PDF HTTP fixture 验证下载事件、拒绝非 PDF、去重、分类、取消与会话关闭。它不进行真实学校登录，不使用真实订阅账号，也不能作为学校/出版社授权成功的证据。
- 专用 GitHub Actions workflow 只运行测试，不发布版本。正式交付前仍需用户在自己的授权机构网络环境中验证实际认证流程。
