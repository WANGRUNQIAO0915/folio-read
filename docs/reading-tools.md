# 阅读工具与快捷键

[返回项目首页](../README.md)

## 选择与复制文字

在中文正文或「对照」中的英文拖选文字，或双击选词，按 `Ctrl+C` 复制，再到其他软件按 `Ctrl+V` 粘贴。正文顶部的「复制」按钮也可复制选区。

原 PDF 页面以图片展示，尚不支持直接在该图片上选择文字。知识问答页面可以选择和复制回答文字，也支持 `Ctrl+F` 查找。

## 荧光笔、下划线与注记

选中文字后，点击正文工具栏的「荧光笔」「下划线」或「注记」。支持跨段和对照英文，颜色标注与注记会保存到文章中，重开后恢复。

需要连续标注时，先开启荧光笔或下划线，再拖选文字。按 `Esc` 返回文字选择模式。注记也可以添加到当前段。

## 快捷键

以下快捷键用于阅读正文。光标在输入框中时，数字和字母用于正常输入。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+C` | 复制选中文字。 |
| `Ctrl+F` | 查找当前页面；阅读正文、文献列表及知识问答页面均可使用。 |
| `Enter` / `Shift+Enter` | 查找时跳到下一个 / 上一个结果。 |
| `Ctrl+Shift+H` | 用荧光笔标注选区。 |
| `Ctrl+Shift+U` | 给选区加下划线。 |
| `Ctrl+Shift+N` | 为选区或当前段添加注记。 |
| `Ctrl+Z` | 在正文中撤销本次新建标注；在文本框中撤销编辑。 |
| `1` / `2` / `3` / `4` | 将选区标为黄 / 绿 / 蓝 / 红色。 |
| `M` | 打开全部批注。 |
| `E` | 修改当前段译文。 |
| `Esc` | 退出连续标注模式，返回选择。 |

标注功能用于阅读正文及对照英文。知识问答页支持选择、复制与查找，尚未提供回答文字的颜色标注。
