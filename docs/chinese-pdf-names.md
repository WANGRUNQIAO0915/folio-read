# 中文论文名称与 PDF 下载

Folio Read 测试版可以给论文设置单独的显示名称，并用这个名称下载原 PDF。例如将 `1-s2.0-…pdf` 整理为便于识别的中文名称。

## 使用

1. 在文献库选择一篇论文，打开「中文名称 / PDF 文件名」；也可以先选择多篇，再批量整理名称。
2. 核对本地找到的原题、原文件名与名称建议。已有中文标题优先使用；其他建议来自书目信息、PDF 元数据或第一页文字，仍需核对。
3. 可以直接修改名称。需要翻译时，点击 AI 按钮，检查接收服务、模型地址及将发送的完整文本，再明确同意发送。
4. AI 结果仅是建议。检查或修改后，点击确认应用，才会保存。
5. 用「下载原 PDF」导出，保存对话框将使用整理后的名称。

AI 将英文原题译成中文时，结果标为「AI 翻译（非官方中文题名）」。程序不保证识别或翻译正确，也不会把模型输出当作经过书目核实的官方中文名称。扫描页或缺少可靠标题时，建议手工填写并核对论文首页。

## 数据与隐私

- 打开名称窗口、生成本地建议及手工修改，不会调用外部模型。
- AI 请求仅包含预览中显示的标题；无法取得标题时，可以包含有限的第一页文字。不会为这项功能发送原 PDF、笔记或整篇正文。
- 名称整理单独保存在论文元数据中，保留原题与原文件名。内部论文 ID、原 PDF 字节、正文译文、笔记及引用关系保持不变。
- 不重命名或移动 Google Drive 中原有的 PDF。已配置的资料库同步会包含已确认的名称元数据；阅读备份也保留名称信息。
- 下载名会清理 Windows 不允许的字符、设备保留名和过长部分，并为重名论文添加区分后缀。操作系统保存窗口仍可能询问是否覆盖已有文件，请核对后再保存。
- 手机网页与 Android 共用这部分源码。手机需已在本地保存原 PDF 才能导出；阅读备份 JSON 不能代替原 PDF 备份。

## 升级

升级前退出旧程序并备份整个实际数据目录。旧论文无需重新导入。新增名称功能不迁移或覆盖原 PDF。

Windows 测试包未做 Authenticode 代码签名。自动化使用合成论文和模拟模型响应；真实 AI 服务、真实 Google 账号同步及 Android 实机仍需单独验证。
