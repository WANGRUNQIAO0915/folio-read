# 文献文件夹、标签与 AI 辅助分类

## 手动分类

- 文献库侧栏可以创建、重命名、删除逻辑文件夹。空文件夹也会保存。
- 导入 PDF 时选择目标文件夹；在论文详情点击“移动 / AI 分类”，或通过“选择论文”批量整理。
- 每篇论文放在一个文件夹中，同时可以拥有多个标签。此前版本已有的“分类”继续作为标签保留，不会自动搬进文件夹。
- 文件夹是软件元数据，不对应磁盘或 Google Drive 的实际目录。整理分类不会移动、复制或删除原 PDF。
- 删除文件夹只会让其中的论文显示为“未分类”，标签、论文内容、笔记和 PDF 都保留。重复导入同一 PDF 不会改动已有论文的位置。
- 手机网页与 Android 使用相同的数据结构和界面；手机导入前也可选择文件夹。

## AI 辅助分类

AI 是可选步骤。手动整理不需要配置模型，也不会发送论文内容。

文件夹用于较大的研究主题。AI 默认只选择已有文件夹，优先复用已有标签名称，每篇按需给出 0–4 个标签，不凑满数量或罗列同义关键词。需要扩展主题时，可勾选“允许 AI 建议新文件夹”，每批最多建议一个可长期复用的主题。所有结果仍需检查后保存。手动标签和旧记录不受这个 AI 数量限制，也不会自动清空。

1. 选择一篇或一批论文（每次最多 20 篇）。
2. 打开“AI 建议分类”。先查看接收服务、完整 API 地址、模型和**实际将发送的完整文本**。
3. 发送内容限于标题（每篇最多 300 字符）、摘要（最多 2000 字符）、少量已提取正文（最多 3000 字符），以及已有文件夹和分类信息。不会发送 PDF 文件、页面图片、批注或整篇正文。模型密钥不会放入提示词或同步包；API 鉴权仍会使用你已配置的接口凭据。
4. 明确勾选同意后发送。桌面版使用设置中的 API 问答模型；不启用无法明确显示接收地址的 CLI 模型。手机使用已配置的 API 模型。
5. 生成的结果只是一份草稿。检查或修改建议文件夹、标签，然后“确认应用分类”才保存。

预览过期、模型设置改变、服务报错或响应格式不完整时，不自动保存分类。取消会丢弃建议；已经发送给模型的文字无法撤回。重复点击不会自动追加相同请求。正文里的指令按文献资料处理，模型结果不执行代码、文件操作或外部动作。

## 同步与兼容

连接现有的共享 Google Drive 资料库后，分类在“同步资料库”时同步。空文件夹也参与同步。分类以独立元数据快照同步，分类变化不需要重新上传 PDF 或论文正文，不改变已有批注合并逻辑。

文件夹采用稳定 ID；重命名不改变所属关系。删除记录会保留，另一台离线设备上的旧副本不会把已删除文件夹恢复出来。再次需要同名文件夹时可创建一个新文件夹。

同一论文在两个设备上离线改动分类时，采用时间和事件 ID 的确定性顺序选择一条分类记录，所有设备会收敛到同一结果。文件夹删除优先于旧重命名记录。界面检测到当前设备上的分类已变化时，会要求刷新复核，避免旧草稿覆盖新修改。它不会逐标签合并两份同时发生的改动。

旧阅读文件仍可导入，已有标签保留。导出的新阅读文件可带上该篇论文的分类与文件夹信息；密钥和设备配置不参与导出。旧版客户端无法理解新文件夹，因此请在需要编辑文件夹的设备上升级。旧包缺少分类字段不会清除已保存的新分类。

## 验证范围

新增测试使用合成 PDF、临时资料库及模拟模型/Drive。覆盖手动分类、旧数据、同步、删除记录、AI 确认/取消/失败、重复操作和并发保护。真实 Google OAuth、真实模型服务、Windows 原生窗口和 Android 实机仍需在对应环境验收；这些测试不代表已完成真机验收。
