# 删除与回收站

在文献库选中论文，右侧详情中的「删除论文」会先将本机阅读资料移入回收站；也可以按 Delete，或使用右键菜单。所有入口均需确认。

要批量删除，点「选择论文」，勾选需要移除的论文后点「删除所选」。可全选当前筛选或搜索列表。删除后 12 秒内可点消息中的「撤销」；之后仍能从文献库上方的「回收站」恢复。

回收站支持标题搜索、单篇与批量恢复、单篇与批量永久删除、清空回收站。恢复会保留原 PDF、译文、图片、笔记、标注、阅读位置和分类。若资料库已经重新导入同一论文，恢复会拒绝覆盖现有资料，两份数据均保留。

「永久删除」和「清空回收站」会再次确认；删除的本机 PDF、译文和笔记无法通过应用恢复。原来导入的外部 PDF、Google Drive 和其他设备上的副本保留。本机保存一份已移除论文的标识列表，防止后台云同步将其再次自动下载；仍可主动导入或下载云端副本。

正在排队、翻译、回答问题、生成配图或写入同步资料的论文暂不允许删除。整篇任务可先取消，等实际停止后再删除。批量操作逐篇给出结果，忙碌或文件被占用的论文会留在资料库，并显示具体原因，不会为了删除而强行停止任务。

旧版本 `.trash` 目录中的论文也会列在回收站中。旧回收站条目若残留运行中的任务状态，恢复时改为停止状态，避免自动重启旧任务；已有译文保留，可自行继续翻译。
