# 标题、网址与 DOI 导入

电脑版「导入论文」可填写完整论文标题、HTTP/HTTPS 论文页面、PDF 直链、DOI 或 arXiv 编号。下载到真实 PDF 后才创建文献记录，保留原有文件夹选择、重复文件去重和后台处理流程。

完整标题依次查询 Semantic Scholar、Crossref 和 arXiv。匹配忽略大小写、标点和空白，但不自动选取仅关键词相近的论文。未命中时请核对完整标题，或改用 DOI、论文网址、PDF 文件。

DOI 可填写 `10.…/…`、`doi:10.…/…` 或 `https://doi.org/10.…/…`。程序尝试开放全文地址、Crossref 登记的 PDF 与出版社页面；某个来源失败会继续尝试其他来源。同一次导入不反复请求已经尝试的 URL 或 DOI，限制来源请求数量与等待时间。

失败提示区分网络／代理／HTTPS 连接故障、服务限流、需要登录或订阅、未找到论文及未取得全文。提示留在导入窗口中，可修改输入后重试。网络失败不再显示成「没找到论文」。

自动下载沿用本机现有网络和代理设置，不复制浏览器登录状态，也不绕过网站的登录或订阅要求。普通论文网页未必提供自动下载入口；浏览器下载 PDF 后仍可使用文件导入。检索需要向相关服务发送标题或 DOI，不调用 AI。

验证包含模拟检索响应、真实本机 HTTP 导入与持久化、失败重试及界面行为。外部网站实时可用性取决于网络和访问权限，需要另行实测。
