# Folio Read v1.1.0-dev8

Windows x64 预发布便携版，内部版本 1.1.0.dev8。

本次新增译文 PDF 导出，沿用当前阅读排版，保留 dev7 的删除与回收站、多级文件夹、分类建议和标准引用功能。

- 阅读页顶栏选择「导出 PDF」，默认中文译文，也可选择「逐段中英对照」。Windows 通过 WebView2 直接保存；网页模式与单文件离线 HTML 使用浏览器打印窗口。
- 沿用当前阅读页实际使用的字体、字号、行距、字距、标题层级、段距、图注、公式和三线表样式。正文宽度能放入 A4 可打印区域时保留，超出时才收窄；窄窗口的实际字号与对齐方式也会保留。
- 输出为 A4 白底、15 mm 页边距，深色主题转换为浅色印刷配色。分页时图表、公式可能整体移至下一页，过宽内容会换行或缩小。换行、图表所在页和页码可能变化，不保证与连续阅读页或出版社原 PDF 的版面一致。
- 使用已有译文和最新修改，不调用模型或重新翻译。正在编辑的内容需先保存或取消；网页模式会读取最新保存的数据，浏览器中尚未写入磁盘的修改会明确提示。
- 保留可用图片、图注、公式、表格和参考文献。缺译保留对应原文或原页，并在导出前及 PDF 内提示；缺图尝试原页回退，仍不可用时明确标注。
- 阅读笔记、AI 边注、划线、高亮、工具栏与侧栏不写入译文 PDF。取消保存不报成功，原 PDF 下载保持独立，Windows 保存时禁止用导出文件覆盖原始 PDF。

## 下载与升级

推荐下载 `FolioRead-Windows.zip`，解压后运行 `FolioRead.exe`；也提供独立 EXE。桌面应用无需安装 Python，依赖 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

升级前通过「文件 → 打开数据文件夹」确认实际数据位置，正常退出旧程序后备份整个数据目录，再替换程序，保留原数据目录。独立 EXE 通常在程序旁使用「FolioRead数据」；已有「Folio数据」「EasyRead数据」或 `easyread-personal` 目录时会沿用，实际位置以应用内入口为准。此次更新不要求迁移或删除现有资料库。

- [跨平台及 Chromium 回归](https://github.com/WANGRUNQIAO0915/folio-read/actions/runs/38038556298)通过：Python 回归共 248 项（Windows 跳过 2 项），并覆盖译文修改持久化、真实渲染 DOM、字体 / 实际字号 / 间距 / 版心快照及 Chromium PDF 输出。
- [Windows 打包 EXE / WebView2 原生回归](https://github.com/WANGRUNQIAO0915/folio-read/actions/runs/38038556320)通过：119 项检查，其中 23 项为原生 PDF 检查，覆盖中文与对照 PDF、最新修改、图表、取消后重试及原始数据保护。
- 测试使用合成论文、本地图像及隔离资料库，无真实文献、账号、API Key 或模型请求。CI 替换了保存位置选择器，生成 PDF 使用真实 WebView2；系统文件对话框的人工点击、取消与覆盖确认仍待人工验收。复杂公式、表格及不同电脑的字体仍应结合导出结果核对。

dev8 发布流程针对发布源码重新运行检查并构建 Windows 包，仅在打包 EXE 检查通过后上传附件。发布包的准确源码提交、构建运行链接及原生 EXE 检查结果以附件 `BUILD-INFO.txt` 为准；`FolioRead.exe` 和 `FolioRead-Windows.zip` 的 SHA-256 校验值见 `SHA256SUMS.txt`。

包未进行 Authenticode 代码签名。本次仅整合 PR #12 的译文 PDF 功能与版本文档，不更新手机网页 / PWA，也不发布 Android APK。

详细操作与限制见[译文 PDF 导出](https://github.com/WANGRUNQIAO0915/folio-read/blob/v1.1.0-dev8/docs/translated-pdf.md)。

### 发布入口

除既有标签发布流程外，本次使用限定为 `release/v1.1.0-dev8` 的单版本入口。工作流只接受已进入 `main` 的源码，核对内部版本，并将发布标签固定到该次构建的提交；已有 dev8 标签或发布时停止，不覆盖附件，也不启用其他版本的分支自动发布。
