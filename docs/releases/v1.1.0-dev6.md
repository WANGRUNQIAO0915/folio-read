# Folio Read v1.1.0-dev6

Windows x64 预发布便携版，内部版本 1.1.0.dev6。

- 文献库多级文件夹，可新建子目录、移动、折叠，父目录显示所有子目录论文。标签保留并单独折叠。
- 打开分类编辑自动推荐；淡色建议留空采用，填写覆盖，保存后生效。支持停止、取消和手动模式。
- 右侧复制引用采用 APA 7 / GB/T 7714—2015 CSL 模板，按 DOI 获取完整书目，预览缺失项；APA 提供格式化复制，完善 BibTeX。

更新时保留 FolioRead数据目录，只替换程序。多级目录需要所有同步客户端更新；旧客户端不能保留父子关系。本次不发布 Android APK。

包未进行 Authenticode 签名。引用准确性取决于公开书目和本机元数据，应检查预览中的缺失字段提示。
