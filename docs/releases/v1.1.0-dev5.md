Folio Read Windows x64 测试版，应用内部版本为 **1.1.0.dev5**。

本次修复：

- 标题、DOI 和论文网址导入增加检索回退与明确的错误说明；全文需要登录或无法下载时，提示通过浏览器获取后手动导入。
- AI 分类每篇按需建议 **0–4 个标签**，优先复用已有名称；默认使用已有文件夹，勾选允许后每批最多建议一个新文件夹。手动标签和旧记录保留。
- 右侧「原文核对提示」默认关闭，可在「设置 → 翻译」中开启。已有记录保留，译文完整性、JSON 和公式检查继续执行。
- 本机 llama.cpp / DFlash 预设支持按请求关闭思考；切换设置时保留当前服务下的自定义模型名称。

下载 `FolioRead-Windows.zip`，解压后运行 `FolioRead.exe`。升级前退出旧程序并备份实际数据目录，替换程序时保留数据目录。本包未做 Authenticode 代码签名，需要 Microsoft WebView2 Runtime。

源码保留现有 Google Drive、手机网页、资料库问答和阅读工具功能；本次不提供新的 Android APK。手机网页随主分支更新分类规则，已安装 PWA 需关闭所有该站点页面后重开。

构建与验证：Windows 包由 GitHub Actions 干净环境构建，发布前执行 Python / 前端回归及打包 EXE / WebView2 检查。准确源码提交、运行链接与原生检查结果见 `BUILD-INFO.txt`，文件摘要见 `SHA256SUMS.txt`。测试使用临时资料和模拟服务，不代表真实 Google 跨设备同步或所有模型均已验收。
