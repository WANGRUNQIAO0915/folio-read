# Folio Read v1.1.0-dev7

Windows x64 预发布便携版，内部版本 1.1.0.dev7。

本次补齐文献库的删除与回收站操作，保留 dev6 的多级文件夹、自动分类建议和标准引用功能。

- 选中论文后，右侧详情直接显示「删除论文」；支持右键菜单、Delete 快捷键和批量选择删除。
- 删除先移入回收站，可立即撤销；顶部「回收站」支持搜索、单篇及批量恢复、永久删除和清空。
- 恢复保留 PDF、译文、图片、笔记、标注、分类与阅读位置；兼容旧回收站记录。同一论文已有本地副本时提示冲突，避免覆盖。
- 排队或运行中的翻译、问答、配图及云同步受到保护；删除不会强制取消任务，批量操作逐篇显示未删除原因。
- 本机删除不会自动删除原始外部 PDF、云盘或其他设备的副本，也不会被后台云同步重新下载。

## 下载与升级

推荐下载 `FolioRead-Windows.zip`，解压后运行 `FolioRead.exe`；也提供独立 EXE。

升级前通过「文件 → 打开数据文件夹」确认实际数据位置并备份，正常退出旧程序后替换程序，保留整个数据目录。首次删除仍可从回收站恢复；永久删除需要再次确认，无法撤销。

## 验证与范围

本地 Python 回归：227 项检查，224 项通过、3 项跳过。隔离资料库验证了单篇和批量删除、撤销、恢复、搜索、冲突及写入保护；打包 EXE / WebView2 启动验证通过。发布包由 GitHub Actions 从此标签源码重新构建，运行结果与源码提交见附件 `BUILD-INFO.txt`，下载校验值见 `SHA256SUMS.txt`。

包未进行 Authenticode 代码签名。本次更新的是 Windows 文献库删除体验，不新增 Android APK；本地删除不执行跨设备删除同步。
